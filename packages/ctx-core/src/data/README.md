# src/data

데이터 영속성 및 접근 계층.

이 모듈은 파일 시스템, Git, 데이터베이스 인덱스와의 모든 상호작용을 담당합니다. `core`나 `app` 레이어는 이 모듈을 통해 데이터에 접근해야 합니다.

## 하위 모듈

- `storage/`: 파일 시스템 접근을 추상화합니다. 현재는 로컬 파일 시스템(`LocalFsStorage`)만 지원합니다.
- `git/`: Git 명령어 실행을 위한 유틸리티를 제공합니다.
- `id/`: 콘텐츠 기반의 안정적인 고유 ID(UUIDv5)를 생성합니다.
- `index/`: 문서 메타데이터를 SQLite 데이터베이스에 인덱싱하고 검색하는 기능을 제공합니다. SCD2(Slowly Changing Dimension Type 2) 모델을 사용하여 문서 변경 이력을 관리합니다.
- `optimization/`: 데이터베이스 쿼리 성능 분석 및 최적화 도구를 제공합니다.
