# ctx 프로젝트 구조

**마지막 업데이트: 2025-08-30**

## 1. 개요

이 문서는 `ctx` 리포지토리의 주요 파일 및 디렉토리 구조와 각 컴포넌트의 역할을 설명합니다.

## 2. 최상위 디렉토리 구조

- `Cargo.toml`: Rust 워크스페이스 및 크레이트 매니페스트. `http`, `ui_tauri` 등 기능 플래그(feature)를 통해 빌드 시 포함할 기능을 제어합니다.
- `tauri.conf.json`: Tauri 설정 파일. 프론트엔드 개발 서버(`devPath`) 및 빌드 결과물(`distDir`) 경로를 지정합니다.
- `config.toml`: 애플리케이션의 동작(경로, AI 제공자, 기본값)을 정의하는 설정 파일입니다.
- `docs/`: `ARCHITECTURE.md` 등 프로젝트의 공식 아키텍처 문서가 위치합니다.
- `apps/ui/`: Tauri 컨테이너에서 실행되는 Svelte 5 프론트엔드 SPA입니다.
- `src/`: 모든 Rust 소스 코드가 포함된 메인 디렉토리입니다.
- `tests/`: 통합 테스트 및 골든 테스트 파일이 위치합니다.

## 3. Rust 소스 코드 구조 (`src/`)

- `src/main.rs`: 애플리케이션의 주 진입점. `app::run_app`을 호출하여 실제 로직을 실행합니다.
- `src/lib.rs`: 다른 모듈의 주요 타입을 외부에 공개(re-export)하는 라이브러리 크레이트의 루트입니다.

### `src/app/` - 애플리케이션 및 UI 계층
- `mod.rs`: `clap`을 사용한 CLI 명령어 정의 및 실행 모드(CLI, Server, UI) 분기 처리.
- `ui/`: Tauri UI의 백엔드 로직.
  - `ipc.rs`: 프론트엔드와 통신하는 비동기 함수(Tauri 커맨드) 및 데이터 타입을 정의합니다.
  - `render.rs`: `comrak`과 `ammonia`를 사용해 Markdown을 안전한 HTML로 렌더링합니다.
  - `tauri_app.rs`: Tauri 애플리케이션을 빌드하고 실행하며, IPC 핸들러를 등록합니다.

### `src/drivers/` - 외부 시스템 드라이버
- `storage/`: 스토리지 추상화 (`Storage` 트레이트) 및 구현체.
  - `local.rs`: 로컬 파일 시스템 어댑터. 경로 순회 공격 방지 로직 포함.
  - `cache/`: LRU/TTL 기반의 고성능 인메모리 캐싱 시스템.
- `http/`: Axum 기반 HTTP 서버 드라이버.
- `ai/`: 외부 AI 모델 API 연동을 위한 추상화 계층.
- `mcp/`: 다른 도구와의 연동을 위한 MCP(Model Context Protocol) 서버 구현.

### `src/pipeline/` - 핵심 비즈니스 로직
- `mod.rs`: 7단계 프롬프트 생성 파이프라인 전체를 조율하는 `Pipeline` 구조체를 정의합니다.
- `classifier/`: 텍스트를 분석하여 `Facet`을 추출하는 분류 엔진.
- `scorer/`: 키워드, 신선도, 유사도 등 다양한 기준으로 문서 후보의 점수를 계산합니다.
- `mmr.rs`: 관련성과 다양성을 모두 고려하여 최적의 문서를 선택하는 MMR(Maximal Marginal Relevance) 알고리즘 구현.

### `src/domain/` - 순수 데이터 모델
- `types.rs`: `ContextDocument`, `PromptBundle` 등 핵심 데이터 구조를 정의합니다.
- `errors.rs`: `thiserror`를 사용한 커스텀 에러 타입을 정의합니다.
- `constants/`: 시스템의 결정론성을 보장하기 위해 모든 가중치, 임계값, 기본값을 상수로 중앙 관리합니다.

### 기타 `src/` 디렉토리
- `src/services/`: `pipeline`의 기능을 감싸 CLI 등에서 사용하기 쉬운 유스케이스(Facade)로 제공합니다.
- `src/knowledge/`: 코드와 분리된 지식 베이스(`ontology.yaml`, `rules.yaml`)를 로드하고 파싱합니다.
- `src/doc/`: 표준 문서 형식(`ContextDocument`)의 파싱, 스키마 정의, 검증을 담당합니다.
- `src/util/`: 해시, 파일 처리 등 프로젝트 전반에서 사용되는 유틸리티 함수를 포함합니다.
