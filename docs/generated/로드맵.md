# ctx 향후 방향 및 로드맵

**마지막 업데이트: 2025-08-30**

## 1. 개요

`ctx`의 핵심 아키텍처와 기능은 '안정적(Stable)' 상태로, 결정론적 프롬프트 생성을 위한 견고한 기반을 갖추고 있습니다. 향후 로드맵은 이 기반 위에서 시스템의 지능, 유연성, 그리고 적용 범위를 확장하는 데 중점을 둡니다.

## 2. 단기 목표: 파이프라인 강화

- **새로운 점수 계산 전략 추가**: 현재의 키워드, 신선도, 유사도 외에, Git 히스토리 기반의 중요도, 코드 의존성 분석 등 더 정교한 `scorer` 전략을 개발하여 컨텍스트 선택의 정확도를 높입니다.
- **분류 엔진(Classifier) 고도화**: `knowledge`의 규칙 체계를 확장하여 더 복잡하고 미묘한 의미적 분류가 가능하도록 개선합니다.
- **템플릿 엔진 개선**: 단순한 텍스트 조합을 넘어, 조건부 렌더링이나 반복문 등 더 동적인 로직을 처리할 수 있는 템플릿 기능을 도입하여 프롬프트 구조의 유연성을 높입니다.

## 3. 중기 목표: 확장성 및 연동성 증대

- **AI 제공자(Provider) 확장**: `drivers/ai` 어댑터 패턴을 활용하여, 현재 지원하는 AI 모델 외에 Anthropic Claude, Mistral 등 더 다양한 외부 AI 모델을 쉽게 추가할 수 있도록 지원을 확대합니다.
- **스토리지 어댑터 추가**: `drivers/storage`에 원격 데이터베이스(e.g., PostgreSQL)나 벡터 DB와 연동할 수 있는 새로운 어댑터를 구현하여, 대규모 문서 세트를 처리할 수 있는 기반을 마련합니다.
- **통합 테스트 커버리지 확대**: `tests/` 디렉토리에 더 다양한 시나리오에 대한 통합 테스트와 골든 테스트를 추가하여, 시스템 변경에 따른 안정성을 더욱 견고하게 보장합니다.

## 4. 장기 목표: 생태계 구축

- **IDE 플러그인 개발**: VSCode, JetBrains IDE 등 주요 개발 환경에서 `ctx`의 프롬프트 생성 기능을 직접 호출하고 사용할 수 있는 플러그인을 개발하여 개발자 워크플로우에 더 깊숙이 통합됩니다.
- **Web API 및 대시보드**: `drivers/http`를 확장하여 `ctx`의 기능을 RESTful API로 제공하고, 이를 통해 시스템의 동작을 시각적으로 모니터링하고 설정할 수 있는 웹 기반 대시보드를 구축합니다.
- **커뮤니티 기반 지식 베이스**: 사용자들이 직접 `knowledge` 규칙이나 `scorer` 전략을 공유하고 기여할 수 있는 플랫폼 또는 저장소를 구축하여 `ctx` 생태계를 확장합니다.
